# 全平台优惠券汇总

> 实时更新的全平台CPS优惠信息聚合项目，涵盖外卖、出行、快递、电影票、酒店旅游、网购、话费会员等7大生活领域。

## 📌 项目简介

本项目汇总各大平台的优惠领取链接，帮助用户在日常生活中省钱。所有链接持续更新，欢迎社区贡献。

## 📂 目录结构

```
├── README.md              # 项目说明
├── data/
│   ├── waimai.json        # 外卖优惠
│   ├── chuxing.json       # 出行优惠
│   ├── kuaidi.json        # 快递优惠
│   ├── dianying.json      # 电影票优惠
│   ├── jiudian.json       # 酒店旅游优惠
│   ├── wanggou.json      # 网购查券
│   └── huafei.json        # 话费会员
└── CONTRIBUTING.md        # 贡献指南
```

## 🔗 优惠类型说明

| 类型 | 说明 | 打开方式 |
|------|------|---------|
| H5 | 网页链接 | 浏览器直接打开 |
| 口令 | 淘宝/微信口令 | 复制到对应APP打开 |
| 小程序 | 微信小程序 | 复制到微信打开 |

## 🚀 使用方式

直接查看 `data/` 目录下的对应品类JSON文件，获取最新优惠链接。
